# Pincus Work – Technical Decisions

## Active decisions

1. Flutter remains the application framework.
2. Supabase remains the backend platform.
3. PostgreSQL remains the primary database.
4. Riverpod remains the preferred state-management solution.
5. GoRouter remains the navigation solution.
6. Clean Architecture remains the architectural foundation.
7. Repository Pattern is used for data access.
8. MVVM is used for presentation/application structure.
9. Material 3 is the UI foundation.
10. Mobile First and Responsive Design remain design requirements.
11. Netlify is used for Web hosting.
12. Netlify Functions are not required as the primary backend.

## Decision rule

Do not replace an active technology or architectural decision merely because another technology is available. A change requires a concrete technical, operational or business benefit.
