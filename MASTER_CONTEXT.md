## Architekturentscheidungen

- Flutter bleibt Grundlage.
- Supabase ist Backend und Datenplattform.
- PostgreSQL ist die Datenbank.
- Riverpod bleibt State Management.
- GoRouter bleibt Navigation.
- Clean Architecture bleibt Architekturgrundlage.
- Repository Pattern bleibt bestehen.
- MVVM wird verwendet.
- Material 3 wird verwendet.
- Mobile First und Responsive Design sind verbindlich.
- Netlify dient als Webhosting.
- Netlify Functions sind keine notwendige Backend-Schicht.
