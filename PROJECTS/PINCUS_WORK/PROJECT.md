# Pincus Work – Project Context

## Project identity

Pincus Work is the dedicated software project for the digital ERP, CRM and Baustellenmanagement system of René Pincus – Baum- & Landschaftspflege.

Repository: `StepsInsider/pincus-work-app`
Branch: `main`
Application package: `pincus_work`
Description from `pubspec.yaml`: `Pincus Work ERP System`

## Project role

Pincus Work is a core part of the broader René-Pincus digitalisation strategy. It is intended to connect office processes, customers, Baustellen, employees, time tracking, offers, orders, invoices and documentation.

## Current functional scope

- Authentication / Login
- Dashboard
- Customers
- Baustellen
- Employees
- Time tracking
- Photo documentation
- Calendar
- KPIs
- Offers
- Orders
- Invoices
- Documents / exports

## User roles

- Admin
- Bauleiter
- Vorarbeiter
- Mitarbeiter

## Working rule

Do not treat Pincus Work as an isolated feature project. New changes should be evaluated against the overall ERP/CRM/Baustellen workflow and the existing architecture.
