# Pincus Work

ERP-, CRM- und Baustellenmanagement-System für René Pincus.

Stack:
Flutter + Dart + Supabase + PostgreSQL.

Module:
- Kunden
- Baustellen
- Mitarbeiter
- Zeiterfassung
- Fotos
- Kalender
- KPIs
- Angebote
- Aufträge
- Rechnungen

Architektur:
Clean Architecture + Repository Pattern + MVVM + Riverpod.
