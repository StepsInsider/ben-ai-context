# Pincus Work – Project Context

## Zweck

Pincus Work ist ein langfristig angelegtes ERP-, CRM- und Baustellenmanagement-System für René Pincus – Baum- & Landschaftspflege.

## Ziel

Büro- und Baustellenprozesse sollen möglichst durchgängig digital abgebildet werden.

## Kernbereiche

- Authentifizierung
- Rollen
- Mitarbeiter
- Kunden
- Baustellen
- Zeiterfassung
- Fotos
- Kalender
- Angebote
- Aufträge
- Rechnungen
- Dokumentation
- Fahrzeuge
- Maschinen
- Lager
- Berichte
- KI
- Kommunikation

## Zielgruppen

- Admin
- Bauleiter
- Vorarbeiter
- Mitarbeiter

## Technische Basis

Flutter + Supabase + PostgreSQL + Riverpod + GoRouter.
